# head-of-medici 🏦

> A headless banking portal backend written in PHP, built for exploring financial technology, low-level transaction ledgers, and secure API architectures.

> [!NOTE]
> **Disclaimer:** This is an independent personal research and educational project. It is **not** affiliated with, endorsed by, or integrated with any bank or financial institution in Nepal or elsewhere.

---

### 🔑 Key Features

* **API-First / Headless Architecture:** Completely decoupled backend exposing secure REST endpoints for any frontend client (web, mobile, or CLI).
* **Double-Entry Ledger:** Robust transaction logging system to ensure zero balance discrepancies.
* **Security-First Design:** Implements strict token-based authentication (OAuth2 / Sanctuar/Passport), role-based access control (RBAC), and API rate-limiting.
* **Audit Trails:** Comprehensive logging for high-value financial actions and authentication events.
